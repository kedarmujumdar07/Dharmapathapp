# DharmaPath — Design Prototypes

This repository holds the HTML/CSS/JS design prototypes and visual assets for the DharmaPath app.

## Repository Structure

- `screens/`: Contains screen-by-screen prototype files (HTML/CSS/JS) and their local assets.
  - `login/`: The animated background login screen mockup and optimized assets.
  - `home/`: The dashboard prototype layout.
  - `paths/`: The learning paths screen mockup.
  - `mantra/`: The mantra practicing and chanting screen mockup.
  - `leagues/`: The leagues and leaderboard mockup.
  - `onboarding/` & `preferences/`: Customization flows.
- `shared-assets/`: Fonts, shared SVGs/icons, and branding color guidelines.

---

*Note: This repository is for visual prototyping and design reviews. For the production application code, please refer to the main repository: [dharmapath-app](https://github.com/kedarmujumdar07/dharmapath-app).*
