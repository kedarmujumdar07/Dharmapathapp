# Contributing to DharmaPath

First off, thank you for taking the time to contribute! We welcome contributions from developers, designers, writers, and educators alike.

---

## 🛠️ Development Workflow

1. **Fork the Repository:** Create a personal fork on GitHub.
2. **Clone Locally:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/Dharmapathapp.git
   cd Dharmapathapp
   ```
3. **Keep Branches Clean:** If you plan to submit a contribution, please base it off the `main` branch.
4. **Make Changes:** Keep edits small, concise, and focused. Ensure you follow local TypeScript types and styling rules.
5. **Run Linting & Validation:**
   ```bash
   cd app
   npx tsc --noEmit
   ```
6. **Submit a Pull Request:** Describe your changes in detail, link any relevant issues, and submit.

---

## 🎨 Design Contributions

DharmaPath utilizes a cohesive blueprint visual aesthetic. If you're designing new pages:
- Check existing layouts inside the `/design` folder.
- Align with typography constraints (*Space Grotesk*, *JetBrains Mono*, *Baloo 2*, and *Caveat*).
- Match the premium, flat-vector mascot and badge themes.

---

## 📝 Code of Conduct

Please help us maintain a respectful, welcoming, and inclusive community for everyone. Be supportive and respect other contributors' time and suggestions.
