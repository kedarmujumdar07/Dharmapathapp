# DharmaPath — Flutter Application

DharmaPath is a Flutter-based production application designed as a Duolingo-style learning platform for Hindu Dharma, utilizing a dark-themed, modern aesthetic.

## Architecture & Codebase

- Built using Flutter with Material 3.
- Key pages:
  - **Onboarding Flow**: Interactive screen sequence with animated SVG assets and custom page indicator controls.
  - **Customization Flow**: A multi-step preference setup showing customizable cards and speech bubbles.
  - **Dashboard**: Features cards with complex tech diagonal clipped shapes, streak tracking, and interactive bottom navigation curves.

For the original HTML/CSS/JS design mockups and image asset prototypes, refer to: [dharmapath-design](https://github.com/kedarmujumdar07/dharmapath-design).

## Running the Application

1. Add your assets (videos and image files) into the respective `assets/videos/` and `assets/images/` folders.
2. Run `flutter pub get`.
3. Run `flutter run`.
